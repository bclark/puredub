# PureDub icon

Original artwork generated using the built-in image generation tool on November 25, 2026, then converted to platform icon formats without changing the design. Included under the repository MIT license.

Prompt:

> Create the final app icon for PureDub, an open source cassette digitization desktop application for Windows and macOS. A single centered rounded-square icon, dark ink navy body with a tactile cassette silhouette, two bold clean cyan tape reels, and an amber magnetic tape ribbon transitioning into a clean waveform with three precise track divider marks. Premium professional audio equipment aesthetic, restrained luminous edge accents, subtle dimensional bevel, graphic clarity readable at 32 pixels, strong silhouette and generous inset padding. No text, no letters, no watermark, no surrounding mockup. Square 1024 composition. Transparent outside the rounded-square icon.

Files: puredub.png (master), puredub.ico (Windows), puredub.icns (macOS). Embedded PNG supplies the running GUI icon; Windows resources also embed the ICO.
