# PureDub workbench

Dark professional studio surface, ink navy background (#101820), pale cool text (#E6EEF2), muted slate controls, cyan (#61D9DD) waveform and amber (#F3B66C) playback accents. Color always accompanies text or a marker shape.

One workbench: release browser on the left; imported side, waveform, transport and editable track table in the center. Bottom status area shows work/error messages. Avoid horizontal scrolling; use the vertical window space. Minimum 980 by 700 logical pixels.

Use proportional type for labels and track names, monospace for time and measured audio information. Native file dialogs. Keyboard focus remains visible; controls have descriptive labels and tooltips. Busy work runs away from the UI thread. No fabricated track data in the empty state.
